# Network Rules

Source: https://www.greptile.com/docs/security/network-rules

If your GitHub or GitLab instance restricts inbound traffic to specific IP addresses, you need to allowlist Greptile’s IP range for code review to work.

## [​](#ip-range) IP Range

All Greptile cloud traffic originates from this subnet:

```
18.97.34.0/29
```

Contact [support@greptile.com](mailto:support@greptile.com) if you have questions about your specific network configuration.
