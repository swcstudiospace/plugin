## [Tools](#tools)

[Border-image generator](/en-US/docs/Web/CSS/Guides/Backgrounds_and_borders/Border-image_generator)
:   Generate CSS [`border-image`](/en-US/docs/Web/CSS/Reference/Properties/border-image) values.

[Border-radius generator](/en-US/docs/Web/CSS/Guides/Backgrounds_and_borders/Border-radius_generator)
:   Generate CSS [`border-radius`](/en-US/docs/Web/CSS/Reference/Properties/border-radius) effects.

[Box-shadow generator](/en-US/docs/Web/CSS/Guides/Backgrounds_and_borders/Box-shadow_generator)
:   Add [`box-shadow`](/en-US/docs/Web/CSS/Reference/Properties/box-shadow) effects to your CSS objects.

[Color format converter](/en-US/docs/Web/CSS/Guides/Colors/Color_format_converter)
:   Enter or pick a color and copy its corresponding value in any CSS [color format](/en-US/docs/Web/CSS/Reference/Values/color_value).

[Color mixer](/en-US/docs/Web/CSS/Guides/Colors/Color_mixer)
:   Mix two colors in any color space using the [`color-mix()`](/en-US/docs/Web/CSS/Reference/Values/color_value/color-mix) function and copy the resulting color in any CSS color format.

[Shape generator](/en-US/docs/Web/CSS/Guides/Shapes/Shape_generator)
:   Define coordinates and syntax for [`<basic-shape>`](/en-US/docs/Web/CSS/Reference/Values/basic-shape) features.

You can also use the following resources:

- [W3C CSS Validation Service](https://jigsaw.w3.org/css-validator/ "External link (opens in new tab)"): To check if your CSS is valid. This is an invaluable debugging tool.
- [Firefox Developer Tools](https://firefox-source-docs.mozilla.org/devtools-user/index.html "External link (opens in new tab)"): To view and edit a page's live CSS via the [Inspector](https://firefox-source-docs.mozilla.org/devtools-user/page_inspector/index.html "External link (opens in new tab)") and the [Style Editor](https://firefox-source-docs.mozilla.org/devtools-user/style_editor/index.html "External link (opens in new tab)") tools.
- [Web Developer extension](https://addons.mozilla.org/en-US/firefox/addon/web-developer/ "External link (opens in new tab)"): To track and edit live CSS on websites in Firefox.
