# What’s New in Python

The “What’s New in Python” series of essays takes tours through the most
important changes between major Python versions. They are a “must read” for
anyone wishing to stay up-to-date after a new release.

The “Changelog” is an HTML version of the [file built](https://pypi.org/project/blurb/)
from the contents of the
[Misc/NEWS.d](https://github.com/python/cpython/tree/3.14/Misc/NEWS.d) directory tree, which contains *all* nontrivial changes
to Python for the current version.
